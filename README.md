# Telegram connector

מחבר קטן לשליחת תקציר בעברית לטלגרם: טקסט, קישור מקור לכל פריט ותמונה אופציונלית. Python 3.12 ומעלה, ללא ספריות חיצוניות.

## מצב הפרויקט

זהו כלי עצמאי. הוא **לא מחבר אוטומטית את השיחה עם Instinct לטלגרם**, לא אוסף חדשות ולא מייצר תקציר. יש להכין קובץ JSON ולהריץ אותו בסביבה שבשליטתכם. אין שירות פעיל, אחסון או תזמון אוטומטי בפרויקט.

ברירת המחדל היא תצוגה מקדימה, ללא פנייה לטלגרם. בדיקות הפרויקט משתמשות בחיבור מדומה ואינן מפרסמות הודעות.

## התחלה מהירה

```sh
python -m unittest discover -s tests -v
python connector.py examples/briefing.json
```

## הגדרת בוט ויעד

1. צרו בוט דרך BotFather לפי [מדריך טלגרם](https://core.telegram.org/bots/tutorial#obtain-your-bot-token).
2. שמרו את הטוקן במנהל סודות. אין להעלות אותו ל-GitHub, להדביק בצ'אט, להוסיף לקובץ JSON או לכתוב כפקודת shell שתישמר בהיסטוריה.
3. הזריקו לסביבת הריצה את `TELEGRAM_BOT_TOKEN` ואת `TELEGRAM_CHAT_ID` דרך מנהל הסודות. קובץ `.env.example` הוא תיעוד בלבד ואינו נטען אוטומטית.
4. הגדירו את מזהה היעד המדויק. לערוץ ציבורי ניתן להשתמש ב-`@channel_username`. הוסיפו את הבוט לערוץ והרשו לו לפרסם. לבדיקה בצ'אט פרטי יש לפתוח שיחה עם הבוט תחילה ולהשתמש במזהה המספרי הנכון.
5. בדקו את קובץ התקציר ואת היעד. רק לאחר אישור התוכן והיעד, הריצו:

```sh
python connector.py examples/briefing.json --send
```

הפקודה האחרונה מפרסמת באמת. קובץ הדוגמה הוא הודעת בדיקה ולא חדשות. מומלץ להשתמש קודם בערוץ בדיקה פרטי.

## מבנה הקובץ

```json
{
  "title": "כותרת התקציר",
  "items": [
    {
      "text": "טקסט מאומת",
      "source_url": "https://example.com/source",
      "photo_url": "https://example.com/image.jpg"
    }
  ]
}
```

`photo_url` הוא שדה אופציונלי. התמונה חייבת להיות זמינה לטלגרם דרך כתובת HTTPS ציבורית. אין תמיכה בהעלאת תמונות מקומיות בגרסה זו. אין להשתמש בכתובת תמונה שמכילה סוד או גישה למידע פרטי: טלגרם תיגש אליה ותציג את התמונה למקבלי ההודעה.

כיתוב ארוך מופרד מהתמונה. הודעות ארוכות מפוצלות תוך שמירה על עברית ואימוג'י. הטקסט נשלח כטקסט רגיל, ללא פענוח HTML או Markdown. מגבלות הגודל והצורה של תמונות נאכפות על ידי טלגרם.

## בטיחות ומגבלות

- היעד נקרא רק ממשתנה הסביבה ואינו ניתן להחלפה מתוך קובץ התקציר.
- הפרויקט אינו פותח שרת ציבורי או endpoint שמאפשר לזרים לשלוח הודעות.
- אין ניסיונות שליחה חוזרים אוטומטיים, כדי לצמצם פרסום כפול. אם יש שגיאה או timeout, ייתכן שההודעה האחרונה כבר נשלחה. בדקו את היעד לפני ניסיון נוסף. הרצה חוזרת של הקובץ עלולה לשכפל גם פריטים קודמים.
- אין תמיכה ב-paid broadcast ואין שליחה בתשלום דרך הקוד.
- הבדיקות רצות מקומית בלבד. לא הוגדר תהליך CI או פרסום אוטומטי ב-GitHub.
- אין מנגנון תזמון. חיבור להזנת תוכן יומית ותזמון ב-08:00 לפי `Asia/Jerusalem` הם שלב נפרד, לאחר קביעת סביבת הרצה ואישור יעד ותוכן.
- אם נחשף טוקן, החליפו אותו דרך BotFather. מחיקה מהקובץ אינה מוחקת אותו מהיסטוריית Git.

## מקורות

- [Telegram Bot API](https://core.telegram.org/bots/api): `sendMessage`, `sendPhoto`, HTTPS ומבנה התשובה.
- [סודות ב-GitHub Actions](https://docs.github.com/en/actions/security-for-github-actions/security-guides/using-secrets-in-github-actions), אם תוסיפו בעתיד תהליך פרסום מאושר.
